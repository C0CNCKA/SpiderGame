## 📖 О игре

> *«Вставьте описание сюда»*

Spider Game — это **Новелла Про паучка Франклина**, разработанная на Unity.

Игрок **Выбирает судьбу паучка со спутницей** в мире, **Полном паучьих опасностей**, где каждое решение влияет на **исход жизни паучка**.

### Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/username/SpiderGame.git

# 2. Открыть папку SpiderGame в Unity Hub
# File → Open Project → выбрать папку

# 3. Подождать, пока Unity импортирует все ассеты
```

> ⚠️ Открывай проект через **Unity Hub**, а не двойным кликом по файлам.
